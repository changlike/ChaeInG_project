## 1. 컬러 무드 (2026-07-14 기준)

**귀엽고 통통 튀되 깔끔하게** — 스카이블루(베이스) + 코랄/핑크(포인트)

| 용도 | 컬러 | 사용처 |
|---|---|---|
| 베이스 | 스카이블루 | 배경 아이콘 원형, 카드 배경 요소, 회원가입 버튼 테두리 |
| 포인트 | 코랄/핑크 | 로그인 버튼, 태그 선택 상태, 즐겨찾기 하트, CTA(행동 유도) 요소 |

### 선정 이유
- **블루**: 더마 코스메틱 브랜드(세타필, 라로슈포제 등)가 실제로 쓰는 색, "저자극/신뢰도" 연상 → PRD 핵심 가치(근거 있는 추천)와 부합
- **핑크**: "귀엽게 만들고 싶다"는 취향 반영, 중요한 행동(로그인, 즐겨찾기)에 시선 유도
- 블루+핑크는 실제로 많이 쓰이는 배색이라 자연스러움

### 이전 시도 (기각)
- 코랄/핑크 단독 베이스 → 색조화장품 브랜드 느낌이 강해서 "성분 신뢰도"라는 가치와 결이 안 맞음
- (2026-10-24 재확인) 핑크 베이스(`#e0608a`) + 베리 핑크 포인트(`#c2185b`)로 실제 화면에 입혀 봄 → 같은 이유로 다시 스카이블루 + 코랄 유지

## 2. 러프 와이어프레임 (톤 확인용, 2026-07-14)

## 4. 현재 구현 값 (2026-10-24, `frontend/src/index.css`)

> 위 무드를 코드에 옮긴 값. 색은 전부 `:root` 변수로만 쓰고, 다크 모드는 변수 값만 바꾼다.

| 변수 | 라이트 | 용도 |
|---|---|---|
| `--sky` | `#3a9ad9` | 베이스 블루: 링크, 브랜드 로고, 보조 버튼 테두리, 매칭 배지 |
| `--sky-bg` | `#e8f4fc` | 페이지 배경 위 옅은 블루: 카드 상단 띠, 안내 박스, 선택 안 된 태그 배경 |
| `--coral` | `#ec5f74` | 포인트: 주요 버튼(CTA), 선택된 태그, 찜 하트 |
| `--coral-bg` | `#fdecef` | 옅은 코랄: 선택된 태그 배경 |
| `--warn` | `#b25e09` | 경고(한도 성분, 검수 전) — 탈락이 아니라 **참고용**임을 색으로 구분 |
| `--error` | `#c0392b` | 입력 오류 |

| 컴포넌트 | 규칙 |
|---|---|
| 주요 버튼 (`button`) | 코랄 배경 + 흰 글씨, 둥근 모서리 (로그인, 저장 등 CTA) |
| 보조 버튼 (`.button-outline`) | 흰 배경 + 스카이블루 테두리 (회원가입 이동 등) |
| 태그 (`.tag`) | 기본은 블루 계열, 선택/매칭된 고민은 코랄 (`.tag-on`) |
| 태그 선택 UI (`.tag-toggle`) | 프로필의 고민 선택을 체크박스 대신 눌러서 켜고 끄는 태그로 표시 (와이어프레임 반영) |
| 찜 하트 (`.heart`) | 찜한 상태 ♥ 코랄, 아닌 상태 ♡ 회색 |
| 카드 (`.card`) | 흰 배경, 블루 계열 옅은 테두리, 둥근 모서리 16px |
| 매칭 배지 (`.badge`) | 스카이블루 배경. 매칭 0개면 회색 (`.badge-dim`) |

## 5. 디자인 원칙 (PRD 기반)

1. 추천의 **판단 근거는 항상 화면에 드러낸다** (점수 환산 없이 매칭 개수 그대로 표시)
2. 경고 문구는 **참고용**임을 분명히 한다 (탈락/감점과 구분)
3. 걸러낸 제품도 숨기지 않고 **이유와 함께** 볼 수 있게 한다
