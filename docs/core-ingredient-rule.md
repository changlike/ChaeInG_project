# 핵심 성분 판정 규칙 (제품별 경계 + 제품명 신호)

> 상태: **기획안 (방향 확정, 구현 전)** / 작성: 2026-11-19
> 목적: 제품의 "주력 고민"(`main_concerns`)을 만들 때, 어떤 성분을 "이 제품의 핵심"으로 인정할지 기준을 다시 세운다.

---

## 1. 왜 다시 세우는가

현재 규칙은 성분 사전에 `position_rule`(`top_n` / `any`)을 두고, 고정값 `TOP_N = 20`으로 "앞 20번째까지만 인정"한다. 점검 결과 이 기준은 근거가 약하다.

| 문제 | 내용 |
|---|---|
| 20의 근거가 불확실 | 기존 문서의 "보존제 첫 위치 중앙값 18"은 재현되지 않음. 재계산하면 기준에 따라 6, 15, 19로 달라지고 계산 방식도 확인할 수 없음 |
| 경계가 제품마다 크게 다름 | 1% 이하 성분 마커의 첫 위치가 **1~76번째**로 흩어져 있음 (아래 표). 고정 20은 어떤 제품엔 너무 넓고 어떤 제품엔 너무 좁음 |
| 있다 ≠ 핵심 | `any` 규칙은 극소량만 들어 있어도 고민이 붙음. 반대로 함량이 적어도 제품이 내세우는 핵심 성분은 놓칠 수 있음 |

성분표 표기 규칙: **1% 초과 성분은 함량 많은 순서**, **1% 이하 성분은 순서가 함량과 무관**하다. 따라서 "순서를 믿을 수 있는 구간"은 제품마다 다르다.

### 현황 측정 (104개 제품 기준, 2026-11-19 — 이후 데이터는 100개로 정리됨)

| 마커 기준 | 마커를 찾은 제품 | 경계 위치 범위 | 중앙값 |
|---|---|---|---|
| 엄격: 페녹시에탄올·파라벤류·클로페네신·소듐벤조에이트·포타슘소르베이트·에틸헥실글리세린 | 68개 (36개는 없음) | 7~57 | 19 |
| 넓게: 엄격 + 향료·카보머·잔탄검·이디티에이·구연산·소듐시트레이트·소듐하이드록사이드·아르기닌·색소 | 97개 (7개는 없음) | 1~76 | 15 |

- 이 데이터의 제품은 보존제로 페녹시에탄올을 거의 쓰지 않음 (104개 중 3개). 1,2-헥산다이올(83개)은 보습제로 1% 넘게 쓰일 수 있어 **마커에서 제외**
- 성분 수 중앙값은 33개

## 2. 새 규칙

```
핵심 성분 인정 = ① 그 제품의 경계 앞에 있다
              또는 ② 경계 뒤(소량)에 있지만 제품명에 그 성분이 언급된다
```

### 2-1. 제품별 경계 (C안)
- **경계 = 그 제품에서 처음 나오는 "1% 이하 마커 성분"의 위치**
- 마커가 1% 이하 영역 어디에든 있을 수 있으므로, 이 위치는 실제 1% 경계의 **상한**이다
  - 경계 **뒤**에 있는 성분은 **확실히 소량**이다 → 이 쪽은 근거가 확실
  - 경계 **앞**에 있는 성분은 1%를 넘을 수도, 아닐 수도 있다 → 순서를 믿고 인정하되 "가능성"으로 취급
- 마커는 **넓은 기준**을 사용 (여러 종류의 마커를 쓸수록 상한이 촘촘해짐)
- 마커가 없는 제품(현재 약 7개)은 **대체 경계 = 성분 수의 절반 정도**로 계산한다 (확정). 성분이 많은 제품은 경계도 뒤로 가는 점을 반영하는 방식이며, 비율 자체는 임의로 정한 기준이다(참고: 마커가 있는 제품의 경계 위치 ÷ 전체 성분 수 중앙값은 약 0.55). 결과에는 "경계 추정"으로 표시한다

### 2-2. 제품명 신호 (B안, 메인)
- 제조사가 핵심으로 내세운 성분은 **제품명에 적혀 있다.** 예: "히알루론산 세럼", "TXA 나이아신 흔적 세럼", "레티놀 시카 모공 흔적 앰플", "징크테카 트러블 세럼"
- 104개 중 65개(약 63%)의 제품명에 성분 또는 고민 키워드가 있음
- 경계 뒤(소량)에 있는 성분이라도 **제품명에 언급되면 핵심으로 인정**한다. 함량이 적어도 제품의 핵심인 경우(예: 뒤쪽 히알루론산, 레티놀)를 구제하는 장치
- 제품명의 표현과 성분표의 표기가 다르므로 **별칭 표**가 필요 (아래 4장)
- 제품명에 성분이 없고 경계 앞 근거도 약한 제품은 **"근거 부족"** 으로 표시한다 (억지로 고민을 붙이지 않음)

### 2-3. 기존 사전과의 관계
- `position_rule`(`top_n`/`any`) 구분은 이 규칙 하나로 **대체**된다 (사전에서 열 삭제 또는 무시)
- strong/weak, 계열(family) 1회 반영, 상위 2개 선택 규칙은 **유지**
- 자극 성분 게이트(`irritant_ingredients.csv`) 기준 (확정): 알코올류(`top_n`)는 **제품별 경계 앞이면 탈락, 경계 뒤(소량 확실)면 탈락시키지 않고 "소량 함유" 경고만 표시**한다. 향료·알레르기 유발 성분·에센셜 오일(`any`)은 지금처럼 **위치와 무관하게 탈락**. 경계를 추정한 제품(마커 없음)은 안전 쪽으로 보수적으로 판정하는 방식은 구현 시 확인

### 2-4. 두 겹 구조: 함유 / 주력 (방향 확정, 세부 미정)
- 들어 있는 성분의 **기능은 위치와 무관하게 기록**한다 (= **함유**). 있는 성분을 없다고 하지 않는다
- **주력**은 위 2-1, 2-2의 규칙(경계 앞 또는 제품명 언급)으로 정한다
- 용도 분리: "00 성분 빼고" 같은 요구는 **함유 여부**로 거르고, 고민 매칭 순위는 **주력**으로 정한다. 카드에는 "미백이 주력은 아니지만 나이아신아마이드가 소량 함유" 같은 표시가 가능
- **아직 정하지 않은 것**: 함유 고민을 어떻게 저장할지(컬럼 추가 등), 한 제품 안에서 어느 기능이 더 핵심인지 가르는 방법, 점수 규칙(strong/weak, 제품명 신호 가중) — **성분 분류가 끝나고 데이터 분포를 본 뒤 결정**

### 2-5. 성분 분류 체계 (확정, 2026-11-19)
- **구조 (2026-11-21 변경)**: 성분 → **6개 고민에 직접 태깅**(또는 "연결 없음"). 중간 "역할(기능 그룹)" 단계는 **두지 않는다.** 이유: 역할 대부분이 고민과 1대 1(보습=건조/보습, 미백=미백/톤, 주름개선=주름/탄력)이라 단계를 거칠 이점이 없고, 11개 역할의 기준도 근거가 약했다. 출처의 용어(배합목적 등)는 **근거 문구(basis)에 원문 그대로 기록**해 출처 대조 검수를 유지한다. (이전의 "성분 → 역할 → 고민 2단계"와 11개 역할 초안은 폐기)
- **태그 값**: 6개 고민(여드름/트러블, 모공, 홍조, 건조/보습, 미백/톤, 주름/탄력) 중 하나 이상, 또는 **연결 없음 + 이유**(기반/용제, 처방 보조, 항산화, 식물추출물, 출처 미확인 등). 고민 어휘는 6개 그대로 유지한다
- **출처 용어 → 고민 판단 기준(초안)**: 보습제·피부보습제·수분증발차단제·피부유연화제와 장벽 근거는 건조/보습 / 진정(CosIng)은 홍조(여드름/트러블 포함 여부는 데이터를 보고 성분별로 확정) / 미백(고시)은 미백/톤 / 주름개선(고시)은 주름/탄력 / 각질제거제 등은 모공(여드름/트러블 포함 여부 미정). 이 판단은 설계자 판단이므로 성분마다 `basis`에 남긴다
- **연결 없음 대상**: 항산화, 기반·처방 보조, 식물추출물(기본값)은 고민에 연결하지 않고 이유만 기록한다
- **기반 보습제 (확정, 2026-11-19)**: 글리세린·부틸렌글라이콜·프로판다이올·펜틸렌글라이콜·다이프로필렌글라이콜처럼 대부분의 제품(29~90개)에 공통으로 들어가는 보습·용제 성분은 **태그는 기록하되 주력 판정에서 제외**한다 (함유로만 남김). 단, 출처에 보습 표기가 있는 성분(글리세린 등)만 건조/보습 태그를 달고 나머지는 "연결 없음(기반/용제)"으로 둔다. 건조/보습 쏠림을 줄이고 제품의 특징 성분이 드러나게 하기 위함
- **복수 고민**: 한 성분이 여러 고민에 걸치면 **모두 기록**하고 **대표 고민 1개**를 표시한다. 대표 고민이 주력 판정의 기준이 되고, 나머지는 함유로 남는다
- **표시 요건**: 카드와 설명에는 대표 고민뿐 아니라 **부가 고민도 사용자 고민의 말로 보여준다** (예: "건조/보습 성분이 주력이고, 홍조 케어 성분도 함께 들어 있어요"). 효능을 단정하지 않고 출처로 확인한 것만 표시하며, 근거 수준이 약한 태그는 약하다고 표시한다

| 비타민E·항산화, 계면활성제, 용제, 폴리머, 실리콘, 킬레이트·pH·염, 보존, 향료, 지방산·알코올, 색소, 식물추출물, 발효물 | 연결 없음 | - | 처방 보조·기반, 식물추출물은 기본 연결 없음(일부만 별도 조사) |

- **알지닌 (확정, 2026-11-22)**: 아미노산 계열과 맞춰 **건조/보습(수분·장벽 케어)** 으로 태깅하고 **주름/탄력(탄력 케어)** 도 함께 단다. 사전 배합목적에는 보습·탄력 표기가 없고 알지닌 단독 효능 출처도 찾지 못했으므로, 이 태그는 **설계자 결정**이다 (앞선 "출처 미확인으로 연결 없음"을 대체)
- **주력 보호 원칙 (확정, 2026-11-22)**: 제품의 주력은 **핵심 성분(경계 앞 + 제품명 신호)** 이 정한다. 소량의 부가 성분이 들어 있다는 이유로 주력이 바뀌어서는 안 된다. 예: 나이아신아마이드가 주력인 제품(미백/잡티 케어)에 알지닌이 들어 있어도 주력이 건조/보습으로 바뀌지 않고, 알지닌의 태그는 함유로만 남는다. **점수 규칙을 설계할 때 이 원칙을 반드시 반영한다** (제품명 신호가 있는 고민이 우선, 경계 뒤 성분은 주력 후보가 되지 못함)
- **남은 성분 판단 (확정, 2026-11-22)**: 코직애씨드·알부틴·알파-알부틴 → 미백/톤 (코직애씨드는 식약처 고시 목록에서 확인하지 못했고 리뷰·CIR 근거, 알파-알부틴은 이성질체 간 효능 비교가 엇갈려 근거 약함) / **PDRN·DNA**(소듐디엔에이, 하이드롤라이즈드디엔에이) → 주름/탄력(약함, 펩타이드와 같은 취급, 제품명 신호가 있는 계열이라 연결함. 근거는 세포·상처 치유 중심이고 바르는 제품의 노화 개선 임상은 얇음) / 멜라토닌(항산화 연구는 소규모), 판토테닉애씨드·칼슘판토테네이트·판토락톤(보습 근거는 판테놀에만 있음), 에스에이치-올리고/폴리펩타이드류 성장인자 계열(동료 심사 논문이 임상 근거를 부정) → 연결 없음
- **계열표 점검 이력**: 키워드로 만든 계열표라 오분류가 반복되어(예: 정제수가 식물추출물로, 소듐하이알루로네이트크로스폴리머가 폴리머로, 소듐디엔에이가 보존으로) 834개 성분을 모두 한 번씩 훑어 정정했다. 오류가 없다고 보장하지는 못하며, 최종 안전망은 제품 100개 전수 검수다. 식물추출물(168개)은 기본 연결 없음으로 두었고 티트리·약모밀·쑥·캐모마일·알로에 같은 진정·여드름 홍보 성분은 근거 조사를 하지 않았다
- **2제형 제품 (확정, 2026-11-22)**: (1제)/(2제)처럼 처방이 둘인 제품(현재 "더 비타 A 레티날 샷 타이트닝 듀얼 크림" 1개)은 **제(劑)마다 따로 파싱하고 따로 태깅**한다. 순서가 제 안에서만 함량 순서이므로 위치·경계·핵심 성분 판정도 제마다 계산하고, 파서는 `parse_formulas`로 제별 성분 목록(위치는 제마다 1부터)을 돌려준다. 제품의 주력은 두 제의 결과를 합쳐 정하며 합치는 방식은 점수 규칙 설계 때 정한다. 현재 DB(`product_ingredients`)에는 제를 구분하는 열이 없어 2제형을 그대로 저장하지 못하므로, 저장 방식(열 추가 마이그레이션 등)은 구현 때 정한다
- **한계**: 징크, 펩타이드, 각질(모공), 베타-글루칸은 근거가 약하거나 소규모이고, 대부분의 연구가 복합 제제라 성분 단독 효과는 확정할 수 없다

### 데이터 작업 순서 (확정)
1. 성분 분류 체계(기능 그룹) 확정 — 예: 기반/용제, 보존·점도, 보습, 진정, 미백, 주름, 피지·각질, 장벽, 식물추출물
2. 흔한 32개 성분부터 그룹 지정 (고유 성분 875개 중 20% 이상 제품에 등장). 출처와 함께 제시하고 사람은 출처 대조만 확인
3. 가끔·드문 활성 성분(약 374개)을 그룹별로 분류. 단일 제품에만 나오는 성분(469개)은 후순위, 식물추출물은 한 그룹으로 두거나 보류
4. 전 제품 분류 후 분포를 보고 점수 규칙 결정 → 구현 → 초안 재생성 → 100개 전수 검수

**처리 (확정, 2026-11-21)**: 근거가 약한 성분은 **weak로 낮춘다.** 사전(`ingredient_concern_map.csv`)에서 구아이아줄렌(홍조)만 strong이었으므로 weak로 하향했고, 병풀 유래 성분·판테놀(진정)은 이미 weak라 유지하며 `basis`에 근거 수준을 기록했다. 알란토인·병풀추출물·비사보롤도 홍조 직접 근거는 아니라 weak를 유지한다.

**보습 역할의 배합목적 표기 불일치 (확정, 2026-11-21)**: 히알루론산 계열은 성분마다 표기가 다르다 — 하이드롤라이즈드하이알루로닉애씨드는 "피부컨디셔닝제(보습제)", 소듐하이알루로네이트크로스폴리머는 "피부보습제", 소듐아세틸레이티드하이알루로네이트는 "보습제"인 반면, 소듐하이알루로네이트는 "피부컨디셔닝제", 하이알루로닉애씨드는 "피부컨디셔닝제(기타)"뿐이다. **같은 계열 안에 보습제로 표기된 성분이 있으므로 히알루론산 계열 전체를 보습 역할로 인정한다.** 이 판정은 배합목적을 글자 그대로 쓴 것이 아니라 계열(family) 단위로 추론한 것이므로 출처 수준을 "계열 추론"으로 따로 표시한다.

**장벽 역할 (확정, 2026-11-21)**: 세라마이드엔피의 배합목적은 "헤어컨디셔닝제, 피부컨디셔닝제(기타)"뿐이라 사전에는 장벽이 없다. 장벽 역할(수분 증발을 막고 피부 장벽을 유지)은 **연구 문헌으로 근거를 보완**하고 근거 수준을 "중"으로 기록한다.
- [CIR 2020 세라마이드 안전성 평가](https://pure.psu.edu/en/publications/safety-assessment-of-ceramides-as-used-in-cosmetics/): 화장품에서 주로 헤어컨디셔닝제·피부컨디셔닝제(기타)로 기능. 장벽이라는 공식 기능 용어는 없음
- [COSMILE Europe 성분 설명](https://cosmileeurope.eu/inci/detail/21295/ceramide-ng): 세라마이드가 피부 건조를 막는 자연 장벽을 이룬다고 설명 (2차 자료)
- 임상: 세라마이드NP 함유 에몰리언트 크림이 아토피 성인에서 장벽 지표와 증상의 개선 경향을 보임([PubMed 33984185](https://pubmed.ncbi.nlm.nih.gov/33984185/) 등 검색 결과 기준). 다른 세라마이드 함유 보습제 연구에서 TEWL 감소·수분 개선이 보고됨
- **한계**: 대부분 복합 제제, 소규모, 산업 후원 가능성이 있는 연구라 세라마이드엔피 단독 효과를 분리하기 어렵다. "장벽 유지"는 생리적 기능 설명이며 공식 배합목적 용어가 아님. 장벽 → 건조/보습 연결은 앞서 정한 설계 결정을 따른다

**주의**: CosIng `SOOTHING`은 "피부 불편감 완화"이며 **홍조(redness)와 직접 연결되는 근거가 아니다.** 진정 → 홍조 매핑은 **설계자 판단**이고, 사람 임상 근거는 제한적이라는 점을 한계로 기록한다.

## 3. 마커 목록 (`data/dilution_markers.csv`, 신규 예정)

| 컬럼 | 설명 |
|---|---|
| `ingredient_name` | 마커 성분명 (부분 일치) |
| `group` | 보존제 / 향료 / 점도조절 / pH조절 / 킬레이트 / 색소 |
| `basis` | "통상 1% 이하로 사용"의 근거 |

- 보존제는 사용 한도가 1% 이하로 알려져 있으나, **이 세션에서 출처를 확인하지 못했다.** `basis`에 출처를 달고, 확인되지 않은 항목은 "가정"으로 표기한다
- 채영 님의 검수는 "이 성분이 통상 소량으로 쓰이는가"가 아니라 **"`basis`에 적힌 출처가 실제로 그렇게 말하는가"** 만 확인하는 방식 (성분 전문 지식 불필요)

## 4. 제품명 별칭 표 (`data/name_aliases.csv`, 신규 예정)

| 컬럼 | 예시 |
|---|---|
| `alias` | 나이아신, TXA, 시카, 테카, 히알루, 레티놀, 펩타이드 |
| `matches` | 연결되는 성분 또는 계열 (나이아신아마이드, 트라넥사믹애씨드, 병풀 계열, 히알루론산 계열 …) |

- 약 30개 예상. 사람이 "별칭 → 성분" 대응이 맞는지 확인 (조회 작업)
- 제품명의 **고민 단어**(수분, 진정, 미백, 모공 등) 처리 (확정): **성분 근거가 있을 때만 인정**한다. 제품명에 "수분"이 있고 해당 기능(보습) 성분이 실제로 들어 있을 때만 그 고민을 주력으로 인정하며, 마케팅 문구만으로는 고민을 붙이지 않는다 ("성분 기반" 원칙 유지)

## 5. 한계 (문서·README에 그대로 기록)
- 마커 위치는 1% 경계의 **상한**일 뿐 정확한 경계가 아니다
- 마커 목록과 별칭 표는 휴리스틱이며, 성분 전문가의 검수를 받지 않았다
- 제품명에 성분이 없는 제품(약 37%)은 경계 앞 근거에만 의존해 판정이 약하다
- 마커가 없는 제품은 대체 경계(성분 수의 절반 정도)를 쓰며, 이 비율은 임의 기준이다
