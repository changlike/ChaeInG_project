# 사용자 흐름 (현재 구현 기준)

> 기준: `frontend/src/` (2026-10-24)

## 화면(라우트) 목록

| 경로 | 화면 | 로그인 필요 | 비고 |
|---|---|---|---|
| `/` | - | - | 로그인 상태면 `/recommend`, 아니면 `/login`으로 이동 |
| `/login` | 로그인 | - | 성공 시 토큰 저장 후 원래 가려던 페이지(기본 `/recommend`)로 이동 |
| `/signup` | 회원가입 | - | 성공 후 로그인 화면으로 이동 |
| `/recommend` | 맞춤 추천 | ✔ | 고민 매칭 개수 순 추천, 걸러낸 제품과 사유, 한도 성분 경고. 프로필 없으면 등록 안내 |
| `/profile` | 피부 프로필 | ✔ | 등록/수정 |
| `/products` | 제품 목록·검색 | 조회는 불필요 / 찜하기는 필요 | 카테고리 필터, 제품명 검색 |
| `/favorites` | 내 찜 목록 | ✔ | 찜 취소 |
| `/ingredients` | 성분 검색 | - | 성분 클릭 시 해당 성분이 든 제품 펼침 |

## 핵심 흐름

```mermaid
flowchart TD
    A[회원가입] --> B[로그인]
    B -->|토큰 저장| C[피부 프로필 입력]
    C --> D[제품 목록/검색]
    D -->|찜하기| E[내 찜 목록]
    D --> F[성분 검색]
    F -->|성분 → 제품 역조회| D
    C --> H[맞춤 추천 + 판단 근거]
    C -.->|예정| G[추천 챗봇]
    G -.->|스코어링 엔진 결과 설명| H
```

## 추천 챗봇 흐름 (설계, 미구현)

```mermaid
flowchart TD
    Q[사용자 질문] --> R{의도 분류}
    R -->|성분 질문| S[FAISS 검색 RAG 답변]
    R -->|추천 요청| T[스코어링 엔진 호출]
    T --> U[게이트: 민감성/금지 성분 탈락]
    U --> V[가산점: 고민 매칭 개수]
    V --> W[경고: 한도 성분 표시]
    W --> X[LLM이 결과를 자연어로 설명]
    R -->|그 외| Y[고정 안내 문구]
```
